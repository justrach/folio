handoffs), opens an authored example answer, inspects its source excerpts, then
edits a follow-up note for the team. Different situations have distinct answers,
sources, outcomes and follow-ups. The interface explains what each observation
supports without claiming that an edit will cause a recommendation.

fictional-data label, customer question and example sources. Completion appears

is sent, no account note is persisted, and no provider task is started. Fictional
sources use reserved .example domains and expand inline instead of fetching pages.

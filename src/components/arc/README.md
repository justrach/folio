# Arc UI source

Action Button and motion tokens copied from the public @uiarc registry on 8 November 2026. MIT, copyright Elia Kuratli. See LICENSE.

Sources: https://uiarc.dev/r/action-button.json and https://uiarc.dev/r/arc-motion-tokens.json. No Arc Pro source is included. Folio supplies scoped theme tokens without changing the component state implementation. One deviation: the success tick is `lucide-react`'s `Check` drawn by a CSS stroke animation with the original timing, replacing the hand-written SVG path.
